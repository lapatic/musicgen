# Endless Music Lab

A generative music composer and synthesizer that runs entirely in the browser. No server, no samples, no build step -
plain HTML/CSS/JavaScript, so it works as-is on GitHub Pages.

- 45 styles + a "chaos" mode (random hybrids), 31 synthesized instruments, 18 scales, 8 melody algorithms
- Live controls for tempo, key, scale, chords, instruments, drum/bass/chord step-sequencers, reverb, echo, lo-fi, sidechain, bit-crush...
- Per-layer volume/mute, auto-evolve (wanders between styles forever), shareable links, WAV export, live recording

## Put it on GitHub Pages

1. Create a new repository on GitHub (e.g. `endless-music-lab`) and push **the contents of this folder** to its `main` branch
   (`index.html` must be at the repository root).
   ```
   cd endless-music-site
   git init && git add . && git commit -m "Endless Music Lab"
   git branch -M main
   git remote add origin https://github.com/<you>/endless-music-lab.git
   git push -u origin main
   ```
2. On GitHub: **Settings -> Pages -> Build and deployment -> Deploy from a branch -> `main` / `(root)`** -> Save.
3. After a minute it is live at `https://<you>.github.io/endless-music-lab/`.

## Run it locally

Browsers refuse to start Web Workers from `file://`, so serve the folder instead of double-clicking `index.html`:

```
cd endless-music-site
python3 -m http.server 8000      # then open http://localhost:8000
```

## Files

| file | what it is |
| --- | --- |
| `index.html`, `style.css` | the page |
| `app.js` | UI, bar scheduling, share links, WAV export, recording |
| `audio.js` | Web Audio graph (buses, reverb/echo convolvers, filter, compressor) + WAV encoder |
| `worker.js` | Web Worker that runs the engine off the main thread |
| `engine.js` | the music engine: instruments, drums, scales, song forms, melody modes |
| `data.js` | style / pattern tables (generated from the Python version, `musicgen.py`) |

To add a style, add an entry to `STYLES` in `data.js` (see existing ones; any key from `DEFAULT` can be overridden).

## Notes

- Seeds are deterministic within this JavaScript engine (a shared link always recreates the same piece) but are **not**
  compatible with the Python version's seeds.
- Needs a modern browser (Chrome, Edge, Firefox, Safari 14.1+). On iOS the ring/silent switch can mute web audio.
- Everything it plays is generated by code in the page, so the audio you export is yours to use however you like.
