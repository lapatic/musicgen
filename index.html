How it works

This page is a small music engine written from scratch in JavaScript. A piece is built from a style (tempo range, scale pool, instruments, drum and bass patterns, song form), a chord progression, and a melody mode (repeating motif, random walk, Euclidean rhythm, phasing, cellular automaton, L-system, canon, sparse notes). Every note is synthesized sample by sample - there are no audio files. A Web Worker renders one bar at a time, and the Web Audio API adds reverb, delay, filtering and compression, so it can run forever.

Everything runs on your device. Nothing is uploaded. Share a link to send someone the exact same piece (same seed and tweaks), or export a WAV to use in your own projects - the output is yours to use however you like.
